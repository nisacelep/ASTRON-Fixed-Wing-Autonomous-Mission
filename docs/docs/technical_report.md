# ASTRON Fixed-Wing Autonomous Mission

## 1. Project Overview

Bu projede PX4 SITL ve Gazebo kullanılarak
sabit kanatlı İHA simülasyonu gerçekleştirilmiştir.

## 2. Mission Planning

Uçuş rotası QGroundControl üzerinden
waypoint kullanılarak oluşturulmuştur.

## 3. Python and MAVSDK

Python ve MAVSDK kullanılarak İHA'ya bağlantı
sağlanmış, arm ve mission başlatma işlemleri
gerçekleştirilmiştir.

## 4. Telemetry Monitoring

Uçuş sırasında aşağıdaki veriler takip edilmiştir:

- GPS konumu
- İrtifa
- Yatay hız
- Uçuş modu
- Havada olma durumu

## 5. Flight Results

Simülasyon ortamında sabit kanatlı İHA uçuşu
gerçekleştirilmiş ve uçuş videosu kaydedilmiştir.

## 6. Conclusion

Proje kapsamında PX4, Gazebo, QGroundControl,
Python ve MAVSDK teknolojileri kullanılarak
otonom uçuş simülasyonu gerçekleştirilmiştir.
